▤ Descreva as atividades — o desenho nasce ao lado
Como preencher: uma linha por atividade, na ordem de execução. Em Tipo escolha o elemento BPMN 2.0 (Início, Tarefa, Subprocesso, Decisão, Fim…). Em Raia informe quem executa — cada raia vira uma swimlane. Em Vai para use o nº da linha; para decisões, use Sim:4 | Não:7 (rótulo:linha, separados por “|”). Deixe vazio para seguir a sequência natural.
Posições: o desenho é atualizado enquanto você digita, mas o C-Flow nunca move o que você já posicionou à mão — só coloca no lugar os elementos novos. Para recalcular tudo, use ⇄ Reorganizar.

▦ Gerar processo

A partir do que foi desenhado, o C-Flow gera a documentação do processo: ficha de identificação, SIPOC, atores e raias, tabela de atividades, narrativa sequencial, regras de decisão, inventário de sistemas, leitura de automação (régua N|G|Q) e indicadores sugeridos — pronta para virar PO/IT.

Clique em Gerar documentação para produzir o documento do processo.

⤓ Exportar

Escolha o formato. O arquivo .bpmn preserva a semântica BPMN 2.0 (com diagram interchange, incluindo os pontos das setas) e é o formato recomendado para versionamento. O .vbpm guarda também os campos de negócio (responsável, sistema, N|G|Q, tempos, volumes).

PNG Imagem PNG

Diagrama em alta resolução (3×) com fundo branco, para apresentações e POs.

SVG Imagem vetorial

Vetor sem perda de qualidade. É também o caminho mais estável para abrir no Visio e no PowerPoint.

PDF Documento PDF

Página única em paisagem, com cabeçalho do processo e rodapé de versão.

HTM HTML interativo

Arquivo único com o diagrama e a ficha do processo — abre em qualquer navegador, sem instalação.

XML BPMN 2.0 (.bpmn)

XML padrão OMG com process, laneSet, flowNodes, sequenceFlows e BPMNDI com waypoints.

VDX Visio (.vdx)

Desenho XML do Visio com formas e rótulos. Se a licença bloquear, use o SVG — o Visio importa vetor nativamente.

JSN Projeto C-Flow (.vbpm)

Modelo completo, incluindo campos de negócio, portas e waypoints das setas. Formato de trabalho.

PPT Apresentação (.pptx)

Deck executivo pronto: capa, indicadores, o fluxo em página inteira e um slide por etapa com responsável, sistema e descrição.

CSV Tabela de atividades

Lista de atividades, tipos, raias, sistemas e conexões — para Excel, Power BI ou anexo de PO.

⤒ Leitor / Importar

Abra arquivos já exportados — .bpmn, .xml, .vbpm ou .json — para visualizar, auditar e continuar editando. O leitor lê o diagram interchange quando existir e, quando não existir, aplica auto-layout para reconstruir o desenho.

Arraste o arquivo aqui ou clique para selecionar .bpmn · .xml · .vbpm · .json — o arquivo é lido localmente no seu navegador, nada é enviado para fora.

▶ Modo apresentação

Abre o fluxo em tela cheia, sem paleta, sem barras e sem painéis — pensado para projetar em telão e explicar o processo para a equipe. Use as setas do teclado para percorrer as etapas uma a uma: cada etapa é destacada e sua descrição, responsável e sistema aparecem na tela.

▶ Iniciar apresentação

Tela cheia com o diagrama ampliado. F5 inicia de qualquer lugar do sistema; Esc encerra.

⇥ Passo a passo

Percorra o fluxo etapa por etapa com → e ←. O C-Flow segue a ordem real do processo, dá zoom na etapa e mostra o que é feito, por quem e em qual sistema.

⌨ Comandos

→ / ← etapa · Espaço avança · Home volta ao início · V visão geral · + / − zoom · P ponteiro · Esc sair.
